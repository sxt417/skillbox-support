SkillBox 隐私政策

更新日期：2026年11月10日 / Last updated: November 10, 2026

本地处理

SkillBox 是整理本地 AI Skill 文件的 macOS 工具。应用在你的 Mac 上读取已选择并授权的文件夹，用于展示技能说明、安装位置、文件差异和安装状态。收藏、分类、备注、设置与操作记录保存在本机应用数据目录中。

我们不收集应用数据

SkillBox 没有注册登录、广告、追踪或分析 SDK，不会自动向开发者上传 Skill 文件、文件路径、文件内容、使用记录或个人整理信息。应用不会执行 Skill 中的脚本，也不会自动调用 AI 服务。

文件权限与备份

商店版通过系统文件选择器请求访问文件夹，并在本机保存授权书签，以便后续启动继续访问。安装、替换和移除遵循应用内确认流程；备份保存在本机。你可移除扫描配置，或通过 macOS 管理文件权限。

主动导出与联系

仅在你主动操作时导出整理数据或迁移包，或打开外部网页、编辑器和邮件应用。迁移包可包含你选定的 Skill 文件、收藏、分类、标签、备注、创作标记和原安装目录映射，保存到你选择的位置；应用不会自动上传这些文件。若你自行把迁移包交给他人或云盘，请先确认其中内容可以分享。点击“联系我们”只会准备邮件，不会自动发送邮件或附加本机文件。如果你主动通过邮件发送反馈，开发者会使用你提供的信息回复并解决问题。请不要发送密码、密钥或不希望分享的文件。

主动检查公开来源更新

当你绑定公开 GitHub 仓库并主动检查更新时，应用会向 GitHub API 请求所填写的仓库、分支、子目录及相关文件。GitHub 会接收 IP 地址等正常连接信息；本地 Skill 文件、路径、备注与使用记录不会上传。下载内容暂存在本机，关闭更新窗口时清理；替换前会展示差异并备份原文件。应用不自动轮询、不使用追踪或分析 SDK，不执行下载文件中的脚本。

系统与第三方服务

App Store 下载记录与系统诊断由 Apple 根据其政策处理。外部 AI 工具、编辑器和邮件服务适用各自政策。本支持网站为 GitHub Pages 托管的静态网页，没有设置分析或追踪脚本；访问网站时，托管服务可能处理 IP 地址等连接信息，详见 GitHub 隐私声明。网站访问与本地应用数据相互独立。
