开始使用

在“设置 → 工具与目录”中选择并授权存放 Skill 的实际目录，然后点击“扫描”。支持发现所选位置中的 SKILL.md。如版本提供“扫描范围”，首次扫描时选择并授权搜索位置，也可在设置中更改。系统受保护或未授权的位置可能无法读取。

目录示例与工具兼容

常见目录包括 Codex 的 ~/.agents/skills、~/.codex/skills，以及 Claude Code 的 ~/.claude/skills。其他工具可选择其实际目录。这里的名称仅用于说明文件位置；SkillBox 是独立开发的文件管理工具，不代表与这些工具存在官方合作。是否能运行某项 Skill，取决于对应工具和该 Skill 的环境要求。

添加、查看与整理

点击“添加 Skill”，选择包含 SKILL.md 的本地文件夹，再选择目标目录。确认冲突和备份方案后才会写入。在详情中的“使用说明 / 文件”可查看原文、示例、安装位置与文件内容。收藏、分类和备注保存在本地，不修改 Skill 原文。只读扫描与预览不执行脚本。

找不到 Skill？

  • 确认目录已授权、扫描位置已启用，并包含 SKILL.md。
  • 重新启动后权限失效时，在“设置 → 工具与目录”重新选择实际目录。
  • 符号链接指向授权范围外时，需要单独授权目标位置。
  • Skill 文件存在不代表已成功执行；解析或文件读取问题可在“安装情况”查看。

备份与数据迁移

“设置 → 备份与恢复”提供完整迁移包、操作记录、文件备份和整理数据导入导出。完整迁移包可以包含你选定的 Skill 文件和分类、标签、收藏、备注、创作标记及原环境映射；在另一台 Mac 导入时，需要授权目标目录并预览冲突。仅导出整理数据不包含 Skill 文件。当前没有自动云同步。商店版与独立版的数据目录相互独立；转移整理数据后，需要重新授权外部目录。应用不自动删除文件备份。
