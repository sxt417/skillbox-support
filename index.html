你可能想问

SkillBox 是什么？适合谁使用？

SkillBox 是独立开发者 Tao 制作的免费 macOS 本地 AI Skill 文件管理工具。它适合已经收集或编写 Skill、希望集中查找和整理本地 SKILL.md 文件的用户。它不是在线 Skill 市场，也不运行 AI 模型。

SkillBox 在哪里下载？支持 iPhone 或 Windows 吗？

在 Mac 的 App Store 搜索 SkillBox，选择“Mac App”结果，认准黑底白色方块图标和“所有技能，一处管理”。也可通过本页 App Store 链接直达。当前仅支持 macOS 14 或更新版本，兼容 Apple Silicon 和 Intel Mac；没有 iPhone、iPad 或 Windows 版本。

SkillBox 免费吗？需要账号或 API Key 吗？

SkillBox 免费下载。本地扫描、查看和整理无需注册 SkillBox 账号，也无需 AI API Key。App Store 下载遵循 Apple 的账号要求；实际使用 Skill 的 AI 工具可能有自己的账号和订阅要求。

可以只收藏和整理，不安装 Skill 吗？

可以。扫描到的本地文件可以先查看说明、搜索、分类、加标签、收藏或写备注，不必安装到其他工具。“我的创作”用来标记你自己编写的 Skill；这些整理信息不会改写 Skill 原文。

扫描不到 Skill，或只在某个工具里能看到，怎么办？

确认选择并授权了包含 SKILL.md 的实际文件夹，而且扫描位置已启用。商店版只读取 macOS 已授权范围；授权父目录不一定覆盖指向范围外的符号链接。查看扫描报告里的目录和权限提示，必要时重新选择实际目录，再扫描。检测到文件不等于对应 AI 工具已经启用它。

安装环境矩阵和待处理有什么用？

安装环境矩阵把各 Skill 在不同环境中的检测结果放在一起，区分未发现、未授权与内容差异，并可标记预期环境。“待处理”集中分析需要检查的条目，帮助比较差异、查看位置和预览处理方案。同一份内容安装在多个环境通常是正常情况。

能把 SkillBox 带到另一台 Mac 吗？会自动云同步吗？

可以手动导出完整迁移包，包含你选定的 Skill 文件、分类、标签、收藏、备注、创作标记和原环境映射。在另一台 Mac 导入时，重新授权目标目录并预览冲突后恢复。仅导出整理数据时不包含 Skill 文件。目前没有自动 iCloud 或其他云同步。

SkillBox 会执行脚本、上传文件或偷偷检查更新吗？

SkillBox 不执行 Skill 脚本，也不向开发者上传本地 Skill、路径、备注或资料库。可选的公开 GitHub 来源检查仅在你主动操作时发起网络请求；GitHub 会收到 IP 地址等正常连接信息。文件比较在本地完成，替换前需确认并备份。详见隐私政策。
